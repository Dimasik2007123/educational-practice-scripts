## Замечания к работе одногруппника

### 1. Инструкция запуска

- Файл: `README.md`.
- Место: раздел «Как запустить».
- Ссылка на комментарий: https://github.com/NikachuX/business-center-management-system/commit/7e55e9918e8c433589f3d3e6a910ddf27191517d#commitcomment-211071994.

По инструкции нужно открыть терминал в папке `src` и выполнить `python src/main.py`, но команда не запускается: файл находится в `src/python/main.py`. Также в README отсутствуют версия Java и команды для компиляции и запуска Java-реализации. Предлагаю исправить команду Python и добавить инструкцию для Java.

### 2. Повторное заключение договора

- Файл: `src/java/RentalOffice.java`.
- Место: метод `updatePremiseAndLease()`.
- Ссылка на комментарий: https://github.com/NikachuX/business-center-management-system/commit/7e55e9918e8c433589f3d3e6a910ddf27191517d#commitcomment-211072267

При проверке удалось подписать два договора на одно помещение и один период аренды. Оба договора получили статус `signed`. Предлагаю при подписании проверять, нет ли другого подписанного договора на это помещение с пересекающимся периодом.

### 3. Статус просроченной брони

- Файл: `src/java/Reservation.java`.
- Место: метод `finishAfterSigning()`.
- Ссылка на комментарий: https://github.com/NikachuX/business-center-management-system/commit/7e55e9918e8c433589f3d3e6a910ddf27191517d#commitcomment-211072397

После подписания договора бронь получает статус `converted`, даже если срок её действия уже истёк. Например, бронь на один час получила этот статус после подписания договора через два дня. Предлагаю учитывать срок действия брони при изменении её статуса.

### 4. Продолжительность бронирования

- Файл: `src/java/RentalOffice.java`.
- Место: метод `reservePremise()`.
- Ссылка на комментарий: https://github.com/NikachuX/business-center-management-system/commit/7e55e9918e8c433589f3d3e6a910ddf27191517d#commitcomment-211072602

Параметр `holdPeriod` может быть нулевым или отрицательным. В результате создаётся бронь, срок действия которой уже истёк. Предлагаю отклонять нулевую и отрицательную продолжительность брони.
