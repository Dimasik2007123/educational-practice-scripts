# Учебная практика — КТ2

Зотеев Дмитрий Александрович, ИКБО-10-24.

Тема работы — оформление сделки по продаже недвижимости и передача объекта покупателю. Для КТ2 подготовлены модель бизнес-процесса BPMN, логическая модель данных, блок-схемы и пять алгоритмов на Python.

## Что делают скрипты

- Подбирают объекты по заданным критериям.
- Бронируют объект за клиентом на 14 дней с проверкой конфликтующих броней.
- Оформляют сделку на один или несколько объектов.
- Генерируют случайный шестизначный код постамата и проверяют, что он ещё не занят.
- Считают количество и сумму сделок за выбранный период.

Данные хранятся в `python/data.json`. Скрипты работают с ними в памяти, подключение к БД не требуется.

## Как запустить

Нужен Python 3.13. Дополнительные библиотеки устанавливать не нужно.

Из корня проекта:

```powershell
python python/main.py
```

Можно запустить и через `python python/demo.py` — результат будет тот же. Демо последовательно выполняет все пять операций. Сообщение об отклонении повторной брони ожидаемое: так проверяется защита от двойного бронирования. Код постамата случайный, поэтому при запуске он может отличаться.

По умолчанию используется дата `2026-10-13`. Чтобы указать другую дату и сохранить результат в отдельный JSON:

```powershell
python python/main.py --date 2026-10-15 --output python/result.json
```

Параметр `--data` задаёт путь к входному JSON. Без `--output` результат выводится в консоль, исходный файл не перезаписывается.

## Что лежит в проекте

- `python/` — скрипты и тестовые данные для КТ2.
- `models/` — BPMN, модели данных и блок-схемы. Файлы `.drawio` открываются в draw.io, `bpmn.bpmn` — в bpmn.io.
- `javapr/` — реализация на Java с подключением к PostgreSQL.
- `sql/` — создание и заполнение базы данных.
- `КТ2_для_сдачи/` — комплект материалов для сдачи.
